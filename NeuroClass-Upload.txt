=================================

1. ჩამოტვირთე NeuroClass-GitHub-Pages.zip. Android-ის Files აპში გახსენი არქივი და აირჩიე Extract / ამოარქივება.
2. შედი არსებულ GitHub პროექტში, main ბრენჩზე:
   https://github.com/urushadzesaba8-stack/Neuroclass1/tree/main
3. პროექტის მთავარ საქაღალდეში აირჩიე Add file → Upload files. საჭიროებისას Chrome-ის მენიუში ჩართე Desktop site.
4. ამოარქივებულ საქაღალდეში მონიშნე რვავე HTML ფაილი და ორი საერთო ფაილი (neuroclass.css და neuroclass.js). ატვირთე ათივე ფაილი ერთად, პირდაპირ იქ, სადაც ახლა index.html დევს.
5. GitHub განაახლებს index.html-ს, sins.html-ს და schizas.html-ს იმავე სახელებით. აირჩიე Commit changes. ZIP და ეს ინსტრუქცია GitHub-ზე ასატვირთ ფაილებში არ შედის.
6. როცა GitHub Pages განაახლებს საიტს, გახსენი:
   https://urushadzesaba8-stack.github.io/Neuroclass1/

შემდეგი მოდულის დამატება
------------------------
1. აიღე ყველაზე მსგავსი HTML ფაილი მაგალითად. ქულების დასაჯამებლად გამოიყენე ich-score.html, გრეიდის ასარჩევად schizas.html, ხოლო კრიტერიუმების კომბინაციით გრეიდისთვის modified-fisher.html.
2. შეინახე ახალი, მოკლე ლათინური სახელით, მაგალითად new-module.html. შეცვალე ორივე ენის ტექსტები, ველების ვარიანტები, მაგალითი, ქვიზი და წყაროები.
3. გვერდის ბოლოში id="model" JSON ბლოკში განსაზღვრე შედეგის წესი. "example" მასივის მნიშვნელობები და თანმიმდევრობა უნდა ემთხვეოდეს ფორმის ველებს. ქვიზის "correct" ინდექსი 0-დან იწყება.
4. index.html-ში დააკოპირე ერთი data-module ბარათი, შეცვალე href, ორივე ენის ტექსტი და data-search. აირჩიე არსებული data-category და data-type. განაახლე ზედა ნიშნულში მოდულების რაოდენობა.
5. GitHub-ის იმავე მთავარ საქაღალდეში ატვირთე ახალი HTML და განახლებული index.html. მოდული ავტომატურად ჩაერთვება ძიებასა და ფილტრებში. ბრაუზერში მოსინჯე ორივე ენა და მაგალითის შედეგი.
