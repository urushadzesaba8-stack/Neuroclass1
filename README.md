# NeuroClass — project starter pack

## Project goal
A bilingual (English/Georgian), personal-use, responsive web application for neurology and neurosurgery classifications, grading systems, scores, and validated calculators.

## Phase 1 status
This starter catalog is an **initial discovery list**, not a complete or clinically verified database. It contains candidate systems identified from the Ars Neurochirurgica index and additional commonly used candidates. Do not use it for patient care.

## Files
- `data/classification_catalog.csv` — initial candidate inventory.
- `data/classification_schema.json` — proposed record structure for each classification.
- `docs/source_register.md` — source register and verification policy.
- `docs/phase1_workflow.md` — step-by-step first phase.

## Important rules
1. Do not copy proprietary text, illustrations, tables, or app content without permission.
2. Record the primary publication or official guideline for every scoring algorithm.
3. Separate original and modified versions (e.g. Fisher vs Modified Fisher; original vs modified TICI; original vs modified Raymond-Roy).
4. Every calculator must have independently tested rules and edge cases before clinical use.
5. Store no identifiable patient data in this personal-use prototype.
6. Display version, source, limitations, and last review date for every classification.
